# 견적 화면 수정 안내

`quote-builder.tsx`는 조회 권한을 확인하고 각 영역을 배치합니다. 영역별 수정은 다음 파일에서 진행할 수 있습니다.

| 역할 | 파일 |
| --- | --- |
| 견적 상태, API 호출, 임시 저장·복구, 수정 충돌 처리 | `use-quote-builder.ts` |
| 시나리오 선택, 새 견적 시작 | `quote-toolbar.tsx` |
| 임시 저장 안내와 오류·충돌 안내 | `quote-notices.tsx` |
| 핵심·권장·확장 견적 비교 | `scenario-comparison.tsx` |
| 단가표 선택, 작업 항목 이름·수량·단가 편집 | `quote-items-editor.tsx` |
| 항목별 근거·가정과 빈 가정 일괄 적용, 할인·출처 추가 설정 | `quote-item-basis.tsx` |
| 견적 입력·추가 설정의 반응형 배치 | `quote-builder.css` |
| 승인된 Hallmark 명세서 배치·글자·간격 | `../../hallmark-workbench.css` |
| 합계 미리보기, 세율·유효 기간, 초안 저장 버튼 | `quote-summary.tsx` |
| 견적 발행과 고객 링크 생성·복사·비활성화 | `quote-publication.tsx` |
| 저장한 견적 이력 선택 | `quote-history.tsx` |
| 빈 항목 생성, 서버·AI 항목 변환, 클립보드 복사 | `quotation-helpers.tsx` |

화면 컴포넌트는 `model`에서 필요한 상태와 함수를 꺼내 사용합니다. 타입은 `useQuoteBuilder`의 반환값에서 추론하므로 화면마다 중복으로 선언하지 않습니다. 화면 파일을 병렬로 수정할 수 있으며, 여러 영역이 함께 사용하는 저장 정책과 권한 규칙을 바꿀 때는 훅 담당자와 조율해 주세요.

임시 저장은 사용자·작업 공간·프로젝트별 브라우저 탭 저장소를 사용합니다. 초안 복구, AI 초안 폐기, 다른 사용자의 수정 충돌 처리는 함께 영향을 주므로 훅에 모아 두었습니다. 합계 미리보기와 서버 저장 후 확정 금액의 구분도 유지합니다.

## 기본 표시 원칙

견적은 항목명·예상 금액·계산 요약·저장/발행 작업을 먼저 표시합니다. 항목 편집과 근거, 시나리오 비교, 동료 제안 조합, 계산 조건, 선택 근거, 이력은 기본으로 접습니다. 분석 사용량과 질문 목록, 결과 기록 편집/견적 대비 차이도 사용자가 펼칠 때 표시합니다. 질문 건수·부분 실패·오류·충돌 안내는 숨기지 않습니다.

네이티브 details/summary를 사용해 키보드 조작과 펼침 상태를 제공하고, 접을 때 폼을 언마운트하지 않아 미저장 입력을 유지합니다. 저장·발행 권한 및 서버 계산 계약은 동일합니다.

견적 항목은 같은 name 그룹의 details로 묶어 하나씩 펼칩니다. 선택한 다른 항목으로 이동해도 공수·단가·근거 입력은 그대로 유지됩니다. 앱의 공유 스타일 뒤에 불러오는 `hallmark-workbench.css`는 카드 중첩을 가로 구분선으로 바꾸며, 계산·저장 훅은 변경하지 않습니다.

항목을 펼치면 단가표 선택과 작업명·수량·직접 입력 단가·산정 메모를 먼저 표시합니다. 등록 단가를 선택하면 비어 있는 작업명과 단위·단가를 채우고 기존 작업명은 유지합니다. 할인율과 근거 유형·출처는 추가 설정에 모으며, 출처가 부족하면 접힌 요약에도 안내합니다. 같은 가정 적용은 사용자가 요청할 때 다른 빈 ASSUMPTION 항목에만 내용을 복사하고, 기존 가정과 EVIDENCE 항목은 유지합니다.
