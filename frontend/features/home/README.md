# 메인 소개 화면 수정 안내

주소 `/`는 기존 Next.js 앱 안의 랜딩입니다. 최신 디자인 방향에 따라 짙은 플럼 캔버스와 보라·라벤더 빛을 사용합니다. 이전 밝은 대시보드 히어로는 작업 브랜치의 이전 체크포인트에 보존되어 있습니다.

## 화면 순서

## 예시와 실제 동작의 구분

- 히어로에는 단 하나의 FO-024 문의 카드가 있습니다. 제안 준비가 끝나면 진행 중에서 협상 중으로 이동합니다. 협상 중은 고객 승인이나 계약 성사를 의미하지 않습니다.
- 단계 버튼은 예시 화면 선택입니다. 직접 선택하면 자동 진행을 멈추며, 완료 이력을 새로 만들지 않습니다.
- 검토 패널의 범위 버튼과 아래 슬라이더는 같은 상태를 사용합니다. 카드·제안서 항목·합계·공수 차트·예시 숫자가 함께 갱신됩니다.
- 30만원/일, 10일 또는 13일, 300만원 또는 390만원은 가상의 프로젝트 설명용 값입니다. 서비스 구독 요금, 고객 수, 실제 매출 또는 성과 지표로 표현하지 않습니다.
- 원문/요구사항/가정의 연결과 검토 필요 상태를 명시합니다. 자동 승인·발송·저장·실제 AI/API 호출은 없습니다.
- 기존 `#product`, `#workflow`, `#evidence`, `#audience`, `/workspace` 진입을 유지합니다. `#review`는 실제 계산된 예시 제안서가 있는 대시보드입니다.

## 모션·접근성·성능

첫 페이지 진입 시 중앙 브랜드 배경이 0.78초 안에 축소·사라지며 히어로를 드러냅니다. 숫자 로딩률이나 대기 상태를 주장하지 않으며 포커스·입력을 막지 않습니다. 입력·스크롤, 아래쪽 딥링크, 모바일과 동작 줄이기 환경에서는 생략하거나 즉시 종료합니다.

진행 단계 1.6초와 완료 상태 1초를 번갈아 표시하고, 최종 완료 후 4.2초 뒤 반복합니다. 화면 진입 시 자동 시작하며 시작/재시작 버튼은 없습니다. 일시 정지/계속 제어는 자동 갱신을 멈출 수 있게 제공합니다.

화면 밖·비활성 탭·마우스 오버·내부 키보드 포커스·사용자 정지·동작 줄이기 설정에서는 진행 타이머와 히어로의 주변광 애니메이션을 멈춥니다. 정지 시 진행 타이머를 멈추고 이미 시작된 짧은 카드 이동은 자연스럽게 마무리합니다. 동작 줄이기 환경에서는 위치를 즉시 표시합니다. 모든 observer, timer, listener는 정리됩니다.

동작 줄이기 환경은 완성된 정적 예시로 시작하며, 단계 버튼으로 내용을 확인할 수 있습니다. 자동 상태를 반복 낭독하지 않고 수동 선택 결과만 상태 영역에서 알립니다. 데스크톱의 로고/플레이트 변환은 스크롤에 연결됩니다. 플레이트는 처음부터 문구와 함께 완전히 펼쳐져 있습니다. 읽을 수 있는 구간을 지난 뒤 하나의 스크롤 타임라인으로 접히며, 하나의 F가 아래 연결 허브의 실제 중심으로 이동하고, 같은 크기와 위치에서 허브로 전환됩니다. 역스크롤은 이 경로를 되짚습니다. 언어·폰트·너비 변화는 ResizeObserver로 다시 측정하며, 모바일과 동작 줄이기 환경에서는 읽기 쉬운 정적 장면으로 제공합니다.

원형 공수와 세 열의 예시 숫자·작업 목록·분절 그래프는 첫 화면 진입에만 짧게 채워집니다. 스크린리더에는 정확한 최종 수치만 제공하고, 화면 밖이나 비활성 탭에서는 동작을 완료합니다. 범위 변경은 최신 계산값을 즉시 반영하며 이전 숫자를 남기지 않습니다.

히어로와 하단의 빛은 서로 다른 곡선·굵기·색으로 구성하며 짧은 강조선이 실제 경로를 따라 이동합니다. 중간의 넓은 안개와 주변광은 각 영역이 보일 때만 움직입니다. 입체 막대는 작업별 공수와 연결된 윗면·앞면·옆면을 사용하고, 실제 작업명을 함께 표시합니다. 독립 IntersectionObserver는 화면 밖의 CSS 재생을 멈추며, 비활성 탭·사용자 정지·동작 줄이기도 재생을 멈춥니다. 820px 이하에서는 입자·이동 강조선·안개의 반복 동작을 제거합니다. 이는 구현된 비용 제한이며 실제 모바일 FPS 측정 결과는 아닙니다.

페이지 전체에 overflow 숨김을 적용하지 않습니다. 장식용 빛의 경계만 자체 영역에서 잘라내고, 움직이는 문의 카드의 높이는 그리드 콘텐츠에서 계산해 긴 문구나 대체 폰트에서도 제어 버튼과 겹치지 않게 합니다. 3D 묶음에는 opacity를 적용하지 않아 모든 막대의 옆면이 유지됩니다.

상단 업무 흐름과 히어로·하단 광선은 Three.js(0.186.1, MIT)로 렌더링합니다. 외부 영상·모델·텍스처·원본 템플릿·유료 프롬프트는 포함하지 않습니다. 기존 SVG와 CSS 화면은 GPU 미지원 시 대체 화면입니다.

`workflow-preview.mjs`는 이전 예시이며 현재 랜딩에 연결되지 않습니다. 실제 업무 화면의 `app/components/live-workflow.tsx`나 채팅/백엔드/API는 변경하지 않습니다.

## 2026-10-02 PC 가독성 보정

랜딩에서만 `@fontsource-variable/noto-sans-kr@5.3.0`을 번들링합니다. 한글·Latin·숫자에 같은 Noto Sans KR Variable을 사용하고 unicode-range별 WOFF2와 font-display: swap을 유지합니다. [Fontsource의 글꼴·OFL-1.1 정보](https://fontsource.org/fonts/noto-sans-kr/about). 업무 공간의 전역 글꼴은 변경하지 않습니다. 핵심 제품 설명은 14–16px, 상태·조작 문구는 14px 이상을 기본으로 합니다. 상단 3D 그래프는 투영 후 크기를 고려해 단계와 상세 본문을 15–16px로 표시합니다. 깊이는 장식 프레임과 실제 입체 그래프에 남깁니다.

제품 예시임을 반복하는 안내문과 그래프의 동작 멈추기 버튼은 사용자 요청에 따라 제거했습니다. 하단에는 상태 한 줄만 남기고 외곽 프레임 안에 독립적인 여백을 확보합니다. 단계 직접 선택은 유지하며 수동 선택은 자동 진행만 멈춥니다. 페이지 장식과 다른 섹션의 모션은 계속 동작합니다.

입체 공수 차트의 분리된 장식 덮개와 막대별 등장 지연을 제거했습니다. 모든 막대는 같은 기준선, 같은 색상 체계, 연결된 세 면을 유지하며 높이는 작업일수에 비례합니다. 01·02·03 대신 번역된 작업 이름을 표시합니다.

## 2026-10-03 모션·렌더링 보정

후속 요청에 따라 막대의 연결된 몸체만 100ms 간격으로 740ms 동안 기준선에서 펼쳐집니다. 작업명과 수치는 변형하지 않습니다. 히어로는 밝은 코어·헤일로·필라멘트가 순차 등장하고, 넓은 배경 전체 대신 국소 광원이 밝아졌다가 가라앉습니다.

정밀 포인터에서는 패널·내용·차트가 같은 중심과 보간 속도로 함께 기울어집니다(최대 X 1.8° / Y 2.2°). 움직이지 않는 바깥 앵커에서 좌표를 읽고 패널 하나만 회전시켜, 테두리와 글자가 따로 미끄러지지 않습니다. 단계·보드·차트의 깊이는 4–8px로 고정하며 막대와 라벨, 원형 차트와 숫자가 함께 움직입니다. 내부 요소의 별도 추적 회전·수평 이동·반대 방향 그림자는 없습니다. 스크롤·범위 밖·포커스·정지·동작 줄이기에서는 원위치로 돌아옵니다. 포인터 좌표는 프레임당 한 번 합치고, 경계는 진입/스크롤/크기 변경 때만 다시 읽으며 GSAP 채널을 재사용합니다. 문의 카드는 하나의 의미 있는 콘텐츠를 유지하며 표면만 둥글게 응축·늘어남·복원됩니다. 중단·역선택·언어/크기 변경은 읽을 수 있는 한 장으로 정리합니다.

비교 섹션의 겹친 SVG 블러는 직접 만든 원본 SVG에서 미리 렌더링한 `public/landing/*-glow.webp`로 대체했습니다(두 파일 약126KB). 이 영역은 두 재사용 재질과 한 이동 강조선을 사용하며 실행 중 SVG 블러를 계산하지 않습니다. 큰 안개는 정적이고, 아래쪽 범위 변경은 위쪽 로고 합류의 전체 스크롤 재측정을 유발하지 않습니다. 이는 소스 및 허용된 브라우저에서 확인할 비용 제한이며 사용자 노트북 FPS 측정과 구분합니다.

작업 개수 아래의 축 없는 추세선은 제거하고 동일 크기의 실제 작업 목록으로 교체했습니다. 공수의 크기는 공수 차트에서만 표현합니다. 하단 비교·슬라이더·CTA의 의미 있는 문구는 13–14px로 정리했습니다.

후속 검수는 아이콘·줄바꿈과 같은 요소 안에 섞인 직접 텍스트도 포함합니다. 가정 펼치기·범위 비교 링크·푸터 설명의 작은 글씨를 확대하고, 제안서 표의 장식용 공수 막대는 접근성 트리에서 제외해 같은 일수를 두 번 읽지 않습니다. 보드의 열 제목은 고정 높이 대신 내용에 맞게 늘어나므로 긴 영문이나 대체 글꼴을 위한 공간을 확보합니다. 실제 모바일 렌더링과 글꼴 차단/확대 테스트는 지원 브라우저에서 별도로 실행해야 합니다.

## 2026-10-04 랜딩 전용 운영 반영

`main`의 운영 코드 위에 랜딩 컴포넌트·모션·자산·Noto Sans KR 의존성만 추립니다. 번역 Provider와 사전은 `features/home` 안에서만 동작하며 페이지를 나가면 문서 언어·제목·건너뛰기 링크를 기존 한국어 상태로 복원합니다. 공용 Providers·layout·globals, 로그인·업무 공간·제안·API, 백엔드·Agent·DB·배포 설정은 변경하지 않습니다.

이번 diff는 `frontend/**`에만 있으므로 기존 `Production Auto CD` 경로 필터에 포함되지 않습니다. 백엔드 CD 또는 데이터베이스 마이그레이션을 실행하지 않습니다.

## 2026-10-04 상단 업무 흐름의 실제 3D 장면

대상은 문의 → 요구사항/리스크 → 견적/제안 노드와 그 아래 프로젝트 카드입니다. 공수 막대 차트는 기존 구현을 유지합니다. `use-workflow-depth.ts`가 `webgl/workflow-renderer.ts`를 화면 진입 시 동적 import합니다. `app/workflow-depth.css`는 첫 GPU 프레임 이후에만 HTML 배경을 숨깁니다.

노드와 프로젝트 카드는 둥근 윤곽을 가진 얇은 돌출 메시입니다. `webgl/workflow-surface.ts`의 거리장 셰이더가 단일 경계를 부드럽게 처리하고 차콜색 유리 면·한쪽 반사광·활성 단계의 넓은 광원 이동을 그립니다. 모든 면을 감싸던 밝은 이중 선과 반복 주사선은 제거했습니다. 빈 작업 열은 옅은 배경으로, 결과 카드는 배경 광선을 충분히 가리는 전경으로 구분합니다. 서로 다른 Z 높이의 노드를 연속적인 발광 곡선으로 연결합니다. 단계 선택·자동 진행은 기존 예시 상태를 사용하고, 같은 카드가 실제 깊이 방향으로 떠올라 다음 열로 이동합니다. 글자와 버튼은 React DOM에 남기고 메시의 표면을 같은 카메라로 투영하므로 의미·클릭·키보드 접근성을 유지합니다. 이전 CSS 기울기와 카드 변형은 GPU 장면이 준비되면 제어권을 넘깁니다. 제품 예시 상단의 자동 진행 안내는 노출하지 않습니다.

히어로·하단 광선은 `webgl/light-ribbon.ts`의 직접 작성한 셰이더입니다. 움직이는 막대 대신 코어·헤일로·산란광과 연속 밝기 흐름을 사용합니다. GPU 미지원·context loss는 기존 SVG와 HTML 화면으로 복구합니다. 화면 밖·비활성 탭·동작 줄이기에서는 루프를 멈춥니다. 화면 밖에서도 크기가 바뀌면 투영을 한 번 갱신해 이전 데스크톱 행렬이 모바일 가로 넘침을 만들지 않게 합니다. 820px 이하와 coarse pointer는 상태/크기 변경 때만 완성된 프레임을 그립니다. 데스크톱 최대 40fps, DPR 최대 1.5(모바일 1)로 제한합니다. 사용하지 않던 그림자 맵과 환경 맵 생성은 제거했습니다. 실제 장치 FPS 보장을 뜻하지 않습니다.

`tests/browser/landing-webgl.spec.mjs`에서 실제 노드·카드의 렌더링, 단계/언어 변경, 투영된 클릭 영역, 화면 크기, 정지, GPU 실패 복구를 검사합니다. 기존 `landing-motion.spec.mjs`는 GPU 미지원 환경의 CSS 대체 화면을 검증합니다.

## 2026-10-04 스크롤 펼침과 마감

`WorkflowUnfold`는 별도 고정 스크롤 구간 없이 문의 카드 하나를 다섯 단계로 펼칩니다. 스크롤 위치가 각 카드의 위치·깊이·불투명도와 연결 광선의 진행률을 결정하며 역스크롤은 다시 모읍니다. 데스크톱은 5열, 모바일은 1+2+2 배치입니다. 동작 줄이기와 JavaScript 미실행에서는 모든 단계를 노출합니다. 리사이즈·번역·폰트 로드 시 최종 레이아웃을 다시 측정하고 이벤트가 있을 때만 프레임을 그립니다.

1024px 전후에서는 히어로를 한 열로 전환해 영문 카드가 지나치게 좁아지지 않게 합니다. 별도 마감 검수로 외곽 여백, 텍스트 대비와 줄바꿈, 한국어·영문 반응형, 하단 제안서 표, 스크롤 초기·중간·완료·역방향과 GPU 실패 대체 화면을 확인합니다.
