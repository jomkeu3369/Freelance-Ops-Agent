# 메인 소개 화면 수정 안내

주소 `/`의 화면은 사용자 디자인의 기존 상단 → 공간형 제품 장면 3개 → 시작 안내 → 하단 메뉴입니다. 기존 Next.js 앱 안에서 동작하며 별도 사이트나 외부 제품 데모를 만들지 않습니다.

| 수정 내용 | 파일 |
|---|---|
| 표시 순서 | `home-page.tsx` |
| 상단 메뉴·모바일 탐색·테마 | `components/home-header.tsx` |
| 보존한 히어로·시작 안내·하단 메뉴 | `components/home-sections.tsx` |
| 업무 흐름·검토/제안서·공수와 근거 장면 | `components/product-experience.tsx` |
| 단일 문의의 단계·이력·범위·견적 계산 | `product-demo.mjs` |
| 기존 등장 효과 | `use-home-animation.ts` |
| 히어로 스타일 | `../../app/figma-home.css` |
| 공간형 장면·모바일·동작 축소 스타일 | `../../app/product-demo.css` |
| 장면 추가 영문 | `../../app/lib/ui-home-english.mjs` |

## 장면과 사실성

- 기존 상단의 Pretendard, 보라/라벤더 브랜딩과 배치를 유지합니다. 중간부터 하나의 플럼 배경 안에 큰 타이포·이어지는 빛·반투명 패널을 배치합니다.
- 첫 장면에는 단 하나의 FO-024 문의 카드가 있습니다. 제안 준비가 끝나면 진행 중에서 협상 중으로 이동합니다. 협상 중은 고객 승인이나 계약 성사를 의미하지 않습니다.
- 두 번째 장면의 범위를 바꾸면 같은 `demoQuote`를 사용하는 카드·제안서 항목·합계·공수 차트가 함께 갱신됩니다. 30만원/일, 10일 또는 13일은 가상의 설명용 값이며 실제 견적이나 성과 지표가 아닙니다.
- 원문→요구사항→가정의 연결과 검토 필요 상태를 명시합니다. 자동 승인·발송·저장·실제 AI/API 호출은 없습니다.
- `#product`, `#workflow`, `#evidence`, `#audience` 기존 링크와 `/workspace` 진입을 유지합니다. `#review`는 새 제안서 장면입니다.

## 동작과 접근성

실행 단계 1.6초와 완료 상태 1초를 번갈아 보여 주고, 최종 완료 후 4.2초 뒤 반복합니다. 화면에 20% 이상 들어오면 자동 진행하며 시작/재시작 버튼이 없습니다. 작은 일시 정지/계속 제어는 자동 갱신을 멈출 수 있게 제공합니다.

화면 밖·비활성 탭·마우스 오버·내부 키보드 포커스·사용자 정지·동작 줄이기 설정에서는 타이머가 멈춥니다. 단계나 범위를 직접 선택하면 자동 진행을 멈추고 선택한 결과를 표시합니다. 수동 선택은 완료 이력을 만들지 않습니다. 모든 observer, timer, listener는 정리됩니다.

동작 줄이기 환경은 완성된 정적 초안으로 시작하며, 단계 버튼으로 각 내용을 읽을 수 있습니다. 자동 상태를 실시간으로 반복 낭독하지 않고 수동 선택 결과만 상태 영역에서 알립니다. 좁은 모바일에서는 같은 카드를 짧게 이동시켜 글자 크기를 유지합니다. 외부 영상·이미지·새 런타임 의존성은 추가하지 않았습니다.

`components/demo-project-flow.tsx`와 `workflow-preview.mjs`는 이전 예시 구현이며 현재 랜딩에서 사용하지 않습니다. 실제 업무 화면의 공통 `app/components/live-workflow.tsx`는 변경하지 않습니다.

## 검증

Node 22에서 `npm run preview:check`를 실행합니다. Playwright 테스트는 `tests/browser/ui-ux.spec.mjs`, 데이터/구조 검사는 `tests/product-demo.test.mjs`와 `tests/spatial-home.test.mjs`에 있습니다. 실제 브라우저가 지원되는 환경에서 production 서버를 127.0.0.1:3100으로 시작하고 `npm run test:ui`를 실행합니다. 외부 API 요청은 fixture로 격리됩니다.

클라우드 런타임의 브라우저 실행 제한이 있으면 우회하지 않습니다. 브라우저 discovery는 실행 통과가 아니며, 허용된 작업 브랜치 Preview의 실제 화면 확인과 자동 테스트 결과를 구분해 기록합니다.
