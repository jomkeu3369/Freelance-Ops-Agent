# 메인 소개 화면 수정 안내

주소 `/`는 기존 Next.js 앱 안의 랜딩입니다. 최신 디자인 방향에 따라 짙은 플럼 캔버스와 보라·라벤더 빛을 사용합니다. 이전 밝은 대시보드 히어로는 작업 브랜치의 이전 체크포인트에 보존되어 있습니다.

## 화면 순서

짧은 브랜드 축소 등장 → 고정 내비 → 문의/업무 흐름 히어로 → 다섯 단계 스트립 → 세 개의 교차형 기능 행 → 로고/플레이트 변환 → 두 개의 제품 원칙 패널 → 프로젝트 대시보드 모자이크 → 열린 세 열의 예시 숫자 → 범위 비교 슬라이더와 세 열 → 분할 CTA → 하단 링크.

## 예시와 실제 동작의 구분

- 히어로에는 단 하나의 FO-024 문의 카드가 있습니다. 제안 준비가 끝나면 진행 중에서 협상 중으로 이동합니다. 협상 중은 고객 승인이나 계약 성사를 의미하지 않습니다.
- 단계 버튼은 예시 화면 선택입니다. 직접 선택하면 자동 진행을 멈추며, 완료 이력을 새로 만들지 않습니다.
- 검토 패널의 범위 버튼과 아래 슬라이더는 같은 상태를 사용합니다. 카드·제안서 항목·합계·공수 차트·예시 숫자가 함께 갱신됩니다.
- 30만원/일, 10일 또는 13일, 300만원 또는 390만원은 가상의 프로젝트 설명용 값입니다. 서비스 구독 요금, 고객 수, 실제 매출 또는 성과 지표로 표현하지 않습니다.
- 원문/요구사항/가정의 연결과 검토 필요 상태를 명시합니다. 자동 승인·발송·저장·실제 AI/API 호출은 없습니다.
- 기존 `#product`, `#workflow`, `#evidence`, `#audience`, `/workspace` 진입을 유지합니다. `#review`는 실제 계산된 예시 제안서가 있는 대시보드입니다.

## 모션·접근성·성능

첫 페이지 진입 시 중앙 브랜드 배경이 0.78초 안에 축소·사라지며 히어로를 드러냅니다. 숫자 로딩률이나 대기 상태를 주장하지 않으며 포커스·입력을 막지 않습니다. 입력·스크롤, 아래쪽 딥링크, 모바일과 동작 줄이기 환경에서는 생략하거나 즉시 종료합니다.

진행 단계 1.6초와 완료 상태 1초를 번갈아 표시하고, 최종 완료 후 4.2초 뒤 반복합니다. 화면 진입 시 자동 시작하며 시작/재시작 버튼은 없습니다. 일시 정지/계속 제어는 자동 갱신을 멈출 수 있게 제공합니다.

화면 밖·비활성 탭·마우스 오버·내부 키보드 포커스·사용자 정지·동작 줄이기 설정에서는 진행 타이머와 히어로의 주변광 애니메이션을 멈춥니다. 정지 시 진행 타이머를 멈추고 이미 시작된 짧은 카드 이동은 자연스럽게 마무리합니다. 동작 줄이기 환경에서는 위치를 즉시 표시합니다. 모든 observer, timer, listener는 정리됩니다.

동작 줄이기 환경은 완성된 정적 예시로 시작하며, 단계 버튼으로 내용을 확인할 수 있습니다. 자동 상태를 반복 낭독하지 않고 수동 선택 결과만 상태 영역에서 알립니다. 데스크톱의 로고/플레이트 변환은 스크롤에 연결됩니다. 플레이트는 처음부터 문구와 함께 완전히 펼쳐져 있습니다. 읽을 수 있는 구간을 지난 뒤 하나의 스크롤 타임라인으로 접히며, 하나의 F가 아래 연결 허브의 실제 중심으로 이동하고, 같은 크기와 위치에서 허브로 전환됩니다. 역스크롤은 이 경로를 되짚습니다. 언어·폰트·너비 변화는 ResizeObserver로 다시 측정하며, 모바일과 동작 줄이기 환경에서는 읽기 쉬운 정적 장면으로 제공합니다.

원형 공수와 세 열의 예시 숫자·작업 목록·분절 그래프는 첫 화면 진입에만 짧게 채워집니다. 스크린리더에는 정확한 최종 수치만 제공하고, 화면 밖이나 비활성 탭에서는 동작을 완료합니다. 범위 변경은 최신 계산값을 즉시 반영하며 이전 숫자를 남기지 않습니다.

히어로와 하단의 빛은 서로 다른 곡선·굵기·색으로 구성하며 짧은 강조선이 실제 경로를 따라 이동합니다. 중간의 넓은 안개와 주변광은 각 영역이 보일 때만 움직입니다. 입체 막대는 작업별 공수와 연결된 윗면·앞면·옆면을 사용하고, 실제 작업명을 함께 표시합니다. 독립 IntersectionObserver는 화면 밖의 CSS 재생을 멈추며, 비활성 탭·사용자 정지·동작 줄이기도 재생을 멈춥니다. 820px 이하에서는 입자·이동 강조선·안개의 반복 동작을 제거합니다. 이는 구현된 비용 제한이며 실제 모바일 FPS 측정 결과는 아닙니다.

페이지 전체에 overflow 숨김을 적용하지 않습니다. 장식용 빛의 경계만 자체 영역에서 잘라내고, 움직이는 문의 카드의 높이는 그리드 콘텐츠에서 계산해 긴 문구나 대체 폰트에서도 제어 버튼과 겹치지 않게 합니다. 3D 묶음에는 opacity를 적용하지 않아 모든 막대의 옆면이 유지됩니다.

빛 스트림은 직접 만든 SVG 곡선입니다. 외부 영상/3D 자산, 추가 라이브러리, 원본 템플릿 코드, 유료 프롬프트를 제품에 포함하지 않습니다. 참고용 MP4/프레임은 저장소 밖에 유지합니다. 앱의 기존 GSAP와 아이콘 라이브러리만 사용합니다.

`components/demo-project-flow.tsx`, `workflow-preview.mjs`는 이전 예시이며 현재 랜딩에 연결되지 않습니다. 실제 업무 화면의 `app/components/live-workflow.tsx`나 채팅/백엔드/API는 변경하지 않습니다.

## 검증

Node 22에서 `npm run preview:check`를 실행합니다. Playwright 테스트는 `tests/browser/ui-ux.spec.mjs`, 계산/상태/번역 검사는 `tests/product-demo.test.mjs`, `tests/spatial-home.test.mjs`에 있습니다. 지원되는 브라우저 환경에서 production 서버를 127.0.0.1:3100으로 시작하고 `npm run test:ui`를 실행합니다. 외부 API 요청은 fixture로 격리됩니다.

브라우저 discovery는 실제 실행 통과가 아닙니다. 클라우드 런타임의 기존 브라우저 실행 제한은 우회하지 않으며, 허용된 작업 브랜치 Preview의 실제 화면 확인과 자동 테스트 결과를 구분해 보고합니다.

## 2026-10-02 PC 가독성 보정

랜딩에서만 `@fontsource-variable/noto-sans-kr@5.3.0`을 번들링합니다. 한글·Latin·숫자에 같은 Noto Sans KR Variable을 사용하고 unicode-range별 WOFF2와 font-display: swap을 유지합니다. [Fontsource의 글꼴·OFL-1.1 정보](https://fontsource.org/fonts/noto-sans-kr/about). 업무 공간의 전역 글꼴은 변경하지 않습니다. 핵심 제품 설명은 13–14px, 상태·조작·안내문은 12px 이상을 기본으로 하며 텍스트 면의 3D 원근과 등장 blur를 제거했습니다. 깊이는 장식 프레임과 실제 입체 그래프에 남깁니다.

히어로 가상 예시 안내문은 이제 `.spatial-flow` 내부의 마지막 문단입니다. 콘텐츠 높이·패딩·줄바꿈으로 영역을 확보하며, 자르기나 overflow 숨김으로 감추지 않습니다. 한국어·영어와 각 상태에서 경계를 확인합니다.

입체 공수 차트의 분리된 장식 덮개와 막대별 등장 지연을 제거했습니다. 모든 막대는 같은 기준선, 같은 색상 체계, 연결된 세 면을 유지하며 높이는 작업일수에 비례합니다. 01·02·03 대신 번역된 작업 이름을 표시합니다.

작업 개수 아래의 축 없는 추세선은 제거하고 동일 크기의 실제 작업 목록으로 교체했습니다. 공수의 크기는 공수 차트에서만 표현합니다. 하단 비교·슬라이더·CTA의 의미 있는 문구는 13–14px로 정리했습니다.

후속 검수는 아이콘·줄바꿈과 같은 요소 안에 섞인 직접 텍스트도 포함합니다. 가정 펼치기·범위 비교 링크·푸터 설명의 작은 글씨를 확대하고, 제안서 표의 장식용 공수 막대는 접근성 트리에서 제외해 같은 일수를 두 번 읽지 않습니다. 보드의 열 제목은 고정 높이 대신 내용에 맞게 늘어나므로 긴 영문이나 대체 글꼴을 위한 공간을 확보합니다. 실제 모바일 렌더링과 글꼴 차단/확대 테스트는 지원 브라우저에서 별도로 실행해야 합니다.
