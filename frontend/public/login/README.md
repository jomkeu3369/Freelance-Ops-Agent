# Login scene media

`pet-path-poster-v1.webp` is the approved static pet-path concept image, optimized
from the original `login-pet-path-concept-v1.png` supplied on 2026-10-05. The
composition and characters are unchanged; only proportional resizing to 1600×900
and WebP compression were applied. Result: 113,720 bytes.

This is a still poster, not a video. No moving clip is currently shipped or
requested automatically. Approved MP4/WebM files can be added to `login-media.ts`
after their actual codec, dimensions, size, audio, loop boundary and first frame
are inspected. The existing poster remains the reduced-motion/data-saving/error
fallback. Do not replace it with an invented remote URL.
