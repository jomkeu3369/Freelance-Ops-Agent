# ADR-0032: 개인 펫 프로필과 제한된 자연어 생성

- 상태: Accepted
- 결정일: 2026-09-12
- 근거: 사용자가 3차 외형·성향 생성을 요청했다.

## 결정

- 사용자/workspace마다 세 관점(LEAN/RECOMMENDED/EXPANDED)의 프로필을 Spring에 저장한다. agent.run 권한을 요구하며 다른 사용자의 설정을 변경하지 못한다.
- 이름, 동물 3종, 색상 6종, 액세서리 4종, 말투와 세 가지 우선순위를 닫힌 계약으로 검증한다. 자연어는 Python의 기존 AI Gateway/BYOK를 통해 이 값으로 변환한다. 임의 SVG·스크립트·이미지 URL·명령은 받지 않는다.
- 외형은 공통 SVG 리소스의 조합이다. 모든 상태에서 같은 모습으로 움직이며 별도 이미지 파일 저장·다운로드가 없다. 자유 형태 이미지 생성으로 표시하지 않는다. 프로필 크기는 제한되고 저장 수는 3개다.
- 생성은 명시적으로 선택한 provider/model에서 한 번, 출력 최대 1,000 token, 전체 30초, 사용자/workspace별 UTC 하루 20회(실패 포함)로 제한한다. 원문 설명은 저장하지 않는다. 생성 요청 ID·모델·키 출처·성공 여부·확인된 토큰 사용량을 기록한다. 알려지지 않은 사용량은 0으로 가장하지 않는다. 요청 실패 시 기존 프로필은 보존되며 자동 재시도·fallback을 하지 않는다.
- 생성 결과는 미리보기일 뿐이며 저장 버튼으로 확정한다. 기본값 복원도 같은 저장 절차를 따른다.
- 분석 시작 시 서버가 프로필을 읽고 실행 요청에 스냅샷을 고정한다. 재개와 과거 결과는 원래 프로필을 유지한다. 기존 실행은 기본 프로필로 표시한다.
- 자연어 원문·이름은 분석 지시로 전달하지 않는다. 검증된 성향 enum만 우선순위와 말투 지시로 변환한다. 시나리오의 핵심/권장/확장 의미, 근거, 권한, 계산, 실행 예산은 유지한다.

## 검증 기준

소유자/workspace 격리, 권한 회수, 값·수량 제한, 생성 실패 보존, 호출·시간·일일 상한, 실행 스냅샷, 성향별 프롬프트 변화, 실제 상태별 외형 일관성, 키보드·모바일·동작 줄이기를 검증한다. 실제 모델의 미적 품질과 제공사 청구액은 자동 검사 결과로 주장하지 않는다.
