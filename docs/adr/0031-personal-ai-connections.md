# ADR-0031: 개인 소유 AI 연결과 호출 직전 자격 증명 확인

- 상태: Accepted
- 결정일: 2026-09-12
- 근거: 사용자가 2차 범위를 설정 정리·BYOK로 확정했다. 펫 생성은 3차다.

## 결정

- 일반 설정의 토큰 단가 등록 UI를 AI 연결로 교체한다. 가격 이력·원장·실행 제한은 유지한다.
- 연결은 사용자와 workspace에 함께 귀속된다. Owner도 다른 사용자의 키를 조회·실행하지 못한다. agent.run과 현재 membership을 검사한다.
- 기본 제공 AI는 유지한다. 실행마다 개인 연결 ID 또는 기본 제공을 명시한다. 개인 연결 실패·삭제·제공사 오류 시 기본 키로 전환하지 않는다.
- Spring은 별도 32-byte 운영 키로 AES-256-GCM 암호화하고 연결 ID/workspace/user/provider를 AAD로 묶는다. 마스킹과 연결 모델만 공개하며 원문은 응답·로그·outbox·checkpoint에 저장하지 않는다.
- 등록/교체는 제공사 공식 모델 조회 API로 키와 선택 모델 접근을 확인한 후 저장한다. 이는 생성 품질/잔여 크레딧 보장이 아니다. 임의 endpoint와 임의 모델은 허용하지 않는다.
- Python은 위임 토큰으로 Spring internal credential API를 모델 호출마다 호출한다. 내부 API는 현재 권한·workspace·소유자·provider/model을 재검사한다. 호출별 SDK client를 닫고 원문을 캐시하지 않는다. 이미 전송된 호출은 삭제로 취소되지 않으며 다음 호출부터 차단한다.
- 실행 시작과 재개 시 연결을 재검증한다. 개인 연결 실행을 다른 사용자가 재개할 수 없다. 교체는 같은 연결 ID를 유지하며 다음 호출은 교체된 키를 사용한다.
- BYOK 오류는 기본 제공 모델의 공유 circuit을 열지 않는다. 공통 allowlist·동시성·timeout·budget은 유지한다.
- 개인 키 실행은 270초 이하로 제한하고 dispatch마다 실행 예산 + 30초의 위임 토큰을 발급한다(최대 5분). 60초 토큰이 정상적인 긴 분석 도중 만료되는 문제를 막으며 재개 시 새 토큰을 발급한다. 호출마다 현재 권한을 재검사하므로 토큰 유효 기간 동안의 권한 회수도 적용된다.
- 초기 운영 허용 모델은 기존 OpenAI 목록을 따른다. Gemini 개인 연결의 초기 목록은 공식 모델 목록에서 확인한 gemini-2.5-flash다. 운영자가 별도 목록을 지정할 수 있으며 임의 모델을 입력받지 않는다. BYOK의 SDK 호출은 추적을 비활성화해 호출별 client가 추적 인자로 직렬화될 가능성을 제거한다.
- 비용은 예상치와 제공사 실제 청구/서비스 요금을 구분한다. 연결 ID와 자격 증명 출처를 실행 기록에 남기되 원문은 남기지 않는다.
- 운영 암호화 키는 배포 서버에서 최초 1회 생성해 기존 비공개 환경 파일에 보관한다. 재배포·rollback 시 유지하고 기존 키를 자동 교체하지 않는다. 백업 복구에는 DB와 별도로 해당 키가 필요하다.

## 수용 기준

교차 사용자/workspace, 권한 회수, 삭제·교체·재개, ciphertext/AAD 변조, 잘못된 provider/model, 비노출과 fallback 없음, UI 연결 확인/실패/삭제·모델 선택, CI·배포 readiness를 검증한다. 실제 사용자의 키를 대신 입력하거나 생성 품질을 검증했다고 주장하지 않는다.

## 제공사 계약 확인

- [OpenAI 모델 조회](https://developers.openai.com/api/reference/resources/models): Bearer 인증으로 선택 모델의 접근을 확인한다.
- [Gemini 모델 조회](https://ai.google.dev/api/models), [API 키 헤더](https://ai.google.dev/gemini-api/docs/api-key): URL에 키를 넣지 않고 `x-goog-api-key`를 사용한다.
- 확인일 2026-09-12. 모델 조회 성공은 실제 생성·크레딧 잔액 보장이 아니다.
