# ADR-0033: 모델로 생성하는 픽셀 펫과 단계별 생성 화면

- 상태: Accepted
- 결정일: 2026-10-19
- 근거: 사용자가 요청한 동물의 실제 모델 생성과 픽셀 아트, 생성 화면 개선.

## 결정

- 펫 생성에서 OpenAI Responses의 구조화 출력을 한 번 호출한다. 모델이 이름·성향과 투명 배경의 32×32 픽셀 외형을 직접 만든다. 종을 세 동물 중 하나로 치환하지 않는다.
- 외형은 검증한 색상표와 픽셀 행으로 저장하고 SVG에서 그린다. 외부 이미지 주소나 실행 가능한 SVG는 저장하지 않는다. 기존 동료와 실행 스냅샷은 계속 읽는다.
- 생성은 Spring의 개인 동료 API가 소유한다. Agent는 위임 권한과 영속 USD 예약을 검증하고 모델을 호출한다. 기존 플랫폼의 사용자·전역 금액 한도를 공유한다. 생성 모델은 서버가 명시적으로 구성하며 개인 분석 모델·개인 키로 조용히 전환하지 않는다.
- 생성 작업의 입력 식별자와 지문·결과를 보관한다. 같은 요청은 모델을 다시 호출하지 않고 같은 결과를 읽는다. 응답을 잃거나 호출 결과가 불명확하면 예약을 유지한다. 사용량은 호출 전후에 영속 기록하고 자동 재시도하지 않는다.
- 저장은 생성 결과의 소유자·입력·기준 revision을 다시 확인한다. 클라이언트가 외형이나 성향을 바꿔 저장할 수 없다. 생성과 저장을 분리하고 저장 실패를 이유로 생성 모델을 다시 호출하지 않는다.
- 화면은 목록·입력·생성 중·결과를 구분한다. 편집 중에는 목록을 숨기고 하단의 같은 위치에서 주 작업을 진행한다. 로딩은 실제 요청 상태이며 실패하면 설명을 보존한다.
- 운영 반영은 기존 ADR-0010에 따라 완성한 화면을 검수한 뒤 진행한다.

## 검증

펭귄 등 기존 프리셋에 없는 요청의 실제 모델 출력과 픽셀 외형, 입력 보존·중복 호출 방지·권한 격리·금액 예약·불명확한 사용량 보존·저장 재전송·과거 동료 호환을 확인한다. 생성물의 품질은 실제 출력과 화면을 확인하며 자동 검사만으로 완벽함을 주장하지 않는다.
