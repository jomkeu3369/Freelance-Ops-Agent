- 메인 모바일 헤더의 로그인 링크를 복구했다. 투명한 상단 메뉴는 스크롤 시 본문 위에 겹치지 않도록 변경했다.

## 현재 상태

사용자 요청에 따라 구현 도중 작업을 중단했다. **최종 완료·배포 상태가 아니며, 다른 PC에서 검증과 마무리가 필요하다.**

- 작업 브랜치: `main`
- 커밋·푸시·배포: 수행하지 않음
- 수정 범위: 사용자가 **메인 소개 + 프로젝트 현황 모두**로 명시
- 스타일 지침: 기존 코드 구성 유지, 함수 파라미터 가로 작성, 마지막 콤마 생략, 기존 줄바꿈 존중
- 완료 또는 중단 정리 시 프로젝트 캐시 제거

**다른 PC로 이동할 때 수정 파일뿐 아니라 아래 신규 CSS, 이미지, 이 문서도 함께 전달해야 한다. 현재 변경은 커밋되지 않았으므로 기존 원격 저장소를 clone하는 것만으로는 이어받을 수 없다.** 작업 폴더를 복사하거나, 사용자가 변경을 검토한 뒤 커밋·푸시해야 한다. `node_modules`는 복사하지 않고 대상 PC에서 다시 설치해도 된다.

## 종료 정리

검수용 Next dev 서버(3000), 테스트용 로컬 API 서버(4812), 검수 브라우저를 종료했다. 테스트용 API는 `.figma-check/mock-api.mjs`에 작성했으나 실제 로그인/프로젝트 검수 전에 중단했으며, 임시 폴더는 삭제 대상으로 정리한다. 운영 데이터에 대한 변경은 수행하지 않았다.

`next dev`가 변경한 `frontend/next-env.d.ts`의 dev 경로는 기존 빌드 타입 경로로 복원했다. Next가 생성한 미추적 안내 파일과 `.figma-check`, `.next`, `.npm-cache`, 백엔드와 로컬 worktree의 `.gradle` 캐시를 삭제했다. 의존성 디렉터리 `node_modules` 자체는 캐시가 아니므로 유지하며, 다른 PC에서는 재설치를 권장한다. `git diff --check`는 통과했다.
