## 현재 소스의 제품 경계

새 실행은 OpenAI만 허용하며 Gemini는 이전 기록 호환이다. 신규 기본 제공 AI는 USD 예약·정산 원장을 사용하고 과거 월 5회·고정 주간 크레딧은 현재 제공량 안내가 아니다. 개인 키는 별도 호출·토큰·시간 한도로 실행한다.

가입 확인·이메일 검증·공지의 구현과 실제 메일 전송·관리자 권한 부여를 구분한다. 개인 동료 생성 변경은 [2026-10-19 검증 기록](../testing/pixel-pet-generation-2026-10-19.md)을 따른다. 이전 예산 없는 생성·견적 가정 생성은 차단 상태다. 현재 사용법은 [문서 안내](../README.md)와 [사용량 계약](../testing/platform-usage-api-2026-10-05.md)을 따른다.

- PyTorch 라우팅 head, cross-encoder와 RAG 평가 결과는 당시 고정 평가셋에서 얻은 실험 기록으로 유지합니다.
