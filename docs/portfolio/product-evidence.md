## 작업 브랜치의 변경

- **채팅 중심 업무 공간:** 대화와 현재 프로젝트 맥락, 실행 결과를 연결합니다. 화면의 실행 표시는 실제로 관찰한 상태와 구분해 검증합니다.
- **무료 분석 사용량:** 기본 제공 키 분석에 계정별 월 5회 한도를 구현했습니다. 여러 workspace가 같은 한도를 사용하며 개인 키 분석은 이 월간 한도와 구분됩니다. 이는 소스의 기본값이며 현재 운영 제공량의 약속이 아닙니다.
- **가입·이메일 검증·공지:** 가입 확인 UI와 이메일 검증·운영 공지의 기반 코드를 추가했습니다. 실제 메일 제공사, 전송과 관리자 권한 부여는 활성화하지 않았습니다.
- **OpenAI 전용 전환:** 새 Gemini 호출을 차단하는 변경을 구현했습니다. 과거 실행·연결 이력은 보존하며 OpenAI로 조용히 대체하지 않습니다. 운영 제공사 표기는 통합 배포 확인 뒤 변경합니다.

이 목록은 공개 정책 문서나 실제 이메일 전송·과금·운영 성과의 증거가 아닙니다.
