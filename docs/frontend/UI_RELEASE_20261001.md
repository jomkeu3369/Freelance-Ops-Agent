## 배포 제외

- 미확정 개인정보처리방침·이용약관 초안과 페이지·푸터 링크를 포함하지 않습니다.
- 푸터 링크는 기존 공개 상태와 같습니다. `/privacy`, `/terms`는 이번 변경으로 생성되지 않습니다.
- Backend·Agent·DB·CI/CD·시크릿·인프라 설정은 변경하지 않습니다.
- 외부 AI 호출이나 운영 데이터 생성·삭제 없이 검증합니다.

## 검증
