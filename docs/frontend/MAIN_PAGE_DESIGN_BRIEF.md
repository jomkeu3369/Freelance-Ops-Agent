# 초기 랜딩 디자인 브리프

이 문서는 디자이너에게 전달한 초기 1920×1080 랜딩 설계의 배경을 보존한다. 현재 화면의 색상·섹션·버튼을 그대로 지정하는 명세는 아니다. 현재 구현은 [소개 화면 안내](../../frontend/features/home/README.md), 공통 기준은 [시각 방향](VISUAL_DIRECTION.md)을 따른다.

## 제품이 전달하려던 가치

한국 소프트웨어 개발 프리랜서가 모호한 고객 문의를 요구사항·작업 범위·견적·제안서로 정리하도록 돕는다. 문의 원문, AI 초안, 가정·근거, 사용자가 확정한 결과를 구분한다. AI가 계약·금액·법률 판단을 대신 확정하거나 자동 학습한다고 표현하지 않는다.

방문자가 첫 화면에서 대상 사용자와 결과물을 이해하고 업무 공간으로 이동할 수 있어야 한다. 가짜 고객 후기·고객사·성과 수치, 미확정 가격·무제한 사용·법률 판단 대체를 홍보 자료로 만들지 않는다.

## 초기 화면 구성

도입부 → 견적 업무의 문제 → 처리 흐름 → 결과물 → 근거와 사용자 검토 → 실제 결과 재사용 → 첫 출시 대상 → 시작 행동 → 푸터 순서였다. 요구사항·작업 항목·공수·단가·근거·합계가 하나의 가상 문의에서 일관되게 이어지는 제품 예시를 의도했다.

초기 문구의 주요 행동은 ‘요구사항 정리 시작하기’였으며 로그인·처리 흐름 확인을 보조 행동으로 뒀다. 준비되지 않은 정책 페이지나 확정되지 않은 가격을 실제 기능처럼 연결하지 않는 원칙을 남긴다. 현재 버튼 문구와 공개 경로는 실제 화면에서 확인한다.

## 시각 참고와 이후 변경

초기 [Pinterest 참고 자료](https://kr.pinterest.com/pin/926052742129752155/)에서는 어두운 넓은 배경, 짧은 중앙 문구, 빛에 감싸인 제품 화면과 스크롤 등장을 참고했다. 원본 로고·문구·UI를 복제하는 지침은 아니다.

| 초기 설계 요소 | 당시 제안                                    |
| -------------- | -------------------------------------------- |
| 배경·표면      | `#050708`, `#101316`                         |
| 강조색         | `#FF7A18`, `#FFB15C`                         |
| 본문·보조 글자 | `#F5F7FA`, `#98A1AA`                         |
| 글꼴           | Pretendard Variable, 영문 보조로 Geist 검토  |
| 도입부         | 열린 주황 광선과 아래에서 드러나는 제품 예시 |

이 값은 원래 설계안을 식별하는 기록이다. 이후 적용된 라벤더·보라색, 실제 3D 장면, 로그인 영상과 현재 글꼴을 과거 값으로 되돌리는 기준으로 사용하지 않는다.

## 디자인 전달 기준

1920×1080 시안과 편집 가능한 원본, 사용한 이미지·아이콘·글꼴의 라이선스, 색상·여백·문구·주요 상호작용을 함께 전달한다. 구현 단계에서는 반응형, 접근성, 로딩·빈 결과·오류, 실제 API·권한을 연결한다. 승인·배포 절차는 [협업 문서](DESIGN_IMPLEMENTATION_WORKFLOW.md) 한곳에서 관리한다.

원래 제품 규칙은 [V2 명세](../V2_SPECIFICATION.md), 역할과 검수 경계는 [ADR-0010](../adr/0010-designer-first-frontend-vercel.md)에 근거한다. 초기 화면의 실행 결과는 [프런트엔드 기준선](../testing/frontend-implementation-baseline-2026-08-15.md)에 보존한다.
