# Freelance Ops 시각 방향

> 기준일: 2026-08-15
> 목적: AI 기능은 분명히 보여주되, 화면이 생성형 AI 데모처럼 보이지 않는 업무 제품을 만든다.

## 제품이 보여야 하는 인상

Freelance Ops는 대화를 보여주는 서비스가 아니라 고객 문의를 검토하고 견적을 확정하는 작업 공간이다. 화면의 중심은 AI 애니메이션이나 기술 용어가 아니라 사용자가 지금 읽고 결정해야 하는 내용이어야 한다.

- 차분하고 신뢰할 수 있는 B2B 업무 도구
- 처음 들어와도 다음 행동을 찾기 쉬운 화면
- AI가 초안을 준비하되 사용자가 결정권을 갖는 구조
- 장시간 읽고 편집해도 피로하지 않은 정보 밀도

## 참고한 제품과 적용 원칙

### Linear

- 참고: <https://linear.app/now/behind-the-latest-design-refresh>
- 적용: 내비게이션은 뒤로 물리고 현재 작업 영역에 시선을 모은다.
- 적용: 모든 요소를 강조하지 않고, 제목·본문·보조 정보 사이에 분명한 위계를 둔다.

### Attio

- 참고: <https://attio.com/>
- 적용: 얇은 선과 과도한 장식 대신 정돈된 카드, 충분한 여백, 익숙한 컨트롤을 사용한다.
- 적용: 데이터 화면에서도 제품 소개 페이지처럼 과장된 타이포그래피를 사용하지 않는다.

### Notion Projects

- 참고: <https://www.notion.com/product/projects>
- 적용: 상태와 다음 행동을 사람이 읽는 말로 보여주고, 원시 enum이나 시스템 이벤트는 기본 화면에서 숨긴다.
- 적용: AI는 별도 쇼처럼 표현하지 않고 초안 작성과 다음 행동 제안에 자연스럽게 연결한다.

## 시각 규칙

### 색상

- 기본 배경은 중성 회색과 흰색 계열을 사용한다.
- 강조색은 한 화면에서 하나의 차분한 파란색 계열만 사용한다.
- 성공·경고·오류 색상은 실제 상태 전달에만 사용한다.
- 네온 발광, 여러 색의 그라데이션, 장식용 광원은 사용하지 않는다.
- 선택·포커스·진행 상태도 발광형 외곽선이나 색 번짐을 사용하지 않는다. 키보드 포커스는 중성색 2px outline, 선택 상태는 배경 명도 차이와 얇은 경계로 구분한다.

### 타이포그래피

- 업무 화면의 페이지 제목은 데스크톱에서 약 34~57px 범위를 넘지 않는다.
- 본문과 입력 내용은 최소 14px, 주요 결과는 15~16px 이상을 기준으로 한다.
- 모노스페이스 글꼴은 코드와 식별자에만 사용한다.
- 영문 대문자 섹션 라벨, 과도한 자간, 한 단어씩 등장하는 문장 애니메이션은 피한다.

### 표면과 배치

- 카드 모서리는 8~14px로 통일하고 그림자는 필요한 계층에만 약하게 사용한다.
- 모든 영역을 선으로 나누지 않는다. 관련 정보는 여백과 배경 차이로 먼저 묶는다.
- 사이드바는 탐색을 돕되 콘텐츠보다 강하게 보이지 않도록 한다.
- 표, 보드, 폼은 제목보다 실제 데이터와 입력값의 가독성을 우선한다.

### 움직임

- 진행 상태는 짧은 전환과 단순한 진행 막대로 표현한다.
- 궤도, 입자, 파동, 반복 점멸, 장식용 데이터 패킷은 사용하지 않는다.
- `prefers-reduced-motion` 환경에서도 정보 손실 없이 사용할 수 있어야 한다.

## 문구 규칙

- `WAITING_FOR_USER`, `COMPLETED` 같은 내부 상태값을 그대로 노출하지 않는다.
- `워크플로우`, `오케스트레이션`, `에이전트 실행`보다 `분석`, `확인`, `견적 초안`처럼 업무 언어를 우선한다.
- “결정적으로 적용됩니다”, “안전하게 중단되었습니다”처럼 시스템이 스스로를 설명하는 문장을 줄인다.
- AI는 실제 역할이 필요한 위치에서만 언급한다. 예: `AI가 정리한 견적 초안`.
- 결과 문구는 사용자가 다음에 할 행동까지 함께 알려준다.

## 화면별 기준

| 화면 | 우선 정보 | 피해야 할 표현 |
|---|---|---|
| 랜딩 | 해결하는 업무, 결과물, 검증 방식 | 거대한 추상 문구, AI 능력 과장 |
| 로그인 | 계정 입력과 진입 행동 | 장식용 프로세스 그래프 |
| 프로젝트 현황 | 현재 상태, 다음 행동, 담당 프로젝트 | 빽빽한 격자와 원시 상태값 |
| AI 분석 | 진행 단계, 확인 질문, 근거, 초안 | 네온 노드 그래프와 이벤트 로그 강조 |
| 견적 | 작업 항목, 공수, 단가, 근거, 합계 | AI가 금액을 확정하는 듯한 표현 |
| 설정 | 현재 값, 설명, 저장 행동 | 보이지 않는 입력 경계와 지나친 기술 설명 |

## 구현 확인 항목

- 데스크톱 1920×1080 랜딩과 로그인 화면 확인
- 모바일 390×844 로그인 화면 확인
- 다크·라이트 토큰에서 본문 대비 유지
- 키보드 포커스와 `prefers-reduced-motion` 유지
- 1280×720 계약 fixture에서 프로젝트 현황·완료 분석·AI 견적 초안·설정 화면 확인
- 390×844 계약 fixture에서 프로젝트 현황·설정 화면과 입력 폭 확인
- 원시 실행·견적·계정 상태, 이벤트 이름, 부서 식별자가 기본 화면에 노출되지 않는지 확인
