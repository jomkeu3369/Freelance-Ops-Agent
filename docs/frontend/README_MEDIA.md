# README 제품 미디어

## 2026-09-12 촬영

- 제품 기준: `b6c15f4`의 WorkspaceChrome, ProjectWorkbench 및 workspace 공통 스타일.
- OBS Studio 32.2.1의 브라우저 소스를 Computer Use로 조작했다. 캔버스·출력·브라우저 소스는 모두 1920×1080, 60fps다.
- 로컬 전용 페이지에 합성 프로젝트·단가·견적·분석 이벤트를 제공했다. 고객 데이터, 로그인 정보, API 키는 사용하지 않았다. 임시 페이지/API는 배포하지 않는다.
- UI의 실제 접기·펼치기와 스크롤을 촬영했다. 실제 모델 호출, 서버 저장·발행, 전체 업무 E2E 검증을 의미하지 않는다.
- OBS 원본에서 Higgsfield의 Higgsedit로 세 구간을 편집했다. 생성 모델로 화면·문자·금액을 재구성하지 않았다.
- 최종 MP4는 46초, 1920×1080, H.264, 60fps 고정 프레임, 2,760프레임이다. 음성 트랙은 제거하고 웹 재생용 faststart를 적용했다.

이미지는 `docs/assets/readme/`에 있으며 OBS 원본 프레임에서 추출했다. README에서는 영상 링크와 정지 이미지를 함께 제공한다. GIF는 정확한 60fps 전달용으로 사용하지 않는다.

## 검증과 남은 작업

- 최종 파일의 해상도, 프레임률, 프레임 수, 길이를 ffprobe로 확인했다. 사진 3장과 편집본의 시작·중간·후반 프레임에서 제목, 금액, 접힘 영역, 분석 단계 상태를 육안 검수했다.
- 최초 촬영에서 공통 disclosure CSS 누락을 발견해 폐기하고, workspace의 전체 공통 스타일과 일관된 합성 완료 이벤트로 재촬영했다.
- 고객·문의 등록, 사용자 확인, 결과 기록의 기존 이미지 파일은 보존하며 README에 이전 UI임을 명시한다. 해당 흐름의 최신 재촬영은 남아 있다.
- Figma 대표 이미지의 편집 가능한 원본 제작은 파일을 만들 팀 선택을 기다리고 있다. 현재 상단 이미지는 실제 제품 캡처다.
- 문서·미디어만 배포하며 앱 동작은 변경하지 않는다. 실계정 E2E 및 모델 응답 품질은 이번 검증 범위에 포함하지 않는다.
