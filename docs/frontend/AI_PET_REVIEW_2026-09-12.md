# AI 펫 핵심 흐름 검증 (2026-09-12)

## 구현 범위

ADR-0030과 구현 계획 1~5의 첫 배포다. 일정 거북이·근거 부엉이·수익 고양이가 기존 bounded run과 세 견적안을 표현한다. 공개 의견은 선택적인 `petPerspective` 계약으로 전달하며 과거 실행에 없는 의견은 생성해서 표시하지 않는다. 추가 모델 호출 없이 기존 실행 예산을 유지한다.

Spring 미리보기는 저장과 같은 계산 경로를 사용하고 workspace/quotation.read/write를 검사한다. 항목 조합, 중복 제목 방지, 선택 변경 후 오래된 미리보기 무효화, 전체 항목 교체 고지와 명시적 반영을 제공한다. 저장 전 변경이 있으면 이전 저장 견적 발행을 막는다. 저장·발행·revision API는 유지한다.

## 로컬 검증

- Backend 전체: 229건 중 217 통과, Docker가 필요한 12건 생략, 실패·오류 0. 새 미리보기 테스트 4건에서 서버 단가/최소 금액/할인/위험 대비/세금, 쓰기 없음, 다른 workspace 프로젝트·단가, 권한 부족을 확인했다.
- Agent 전체: 296 통과, DB 통합 8건 생략. Ruff 통과, mypy 81개 소스 통과. 공개 의견의 하위 호환·길이·비공개 추론/금액 필드 거부, 과거 실행 프롬프트 버전 보존을 확인했다.
- Frontend: 55개 테스트, 타입 검사, ESLint, Next 프로덕션 빌드 통과. 최종 로그는 Git 제외 `output/pet-workspace/`에 보존한다.
- OpenAPI 두 계약 유효성 검사 통과. Agent 내부 계약 0.4.2는 선택 필드 추가다.
- 로컬 Chromium 합성 계약 화면에서 1440px 다크, 390px 라이트를 육안 확인했다. 390px에서 문서 너비 375px/내용 너비 375px로 가로 넘침이 없었다. 접기 버튼 줄바꿈을 추가 보완했다.
- 실제 컴포넌트로 중복 항목 차단, 다른 펫의 항목 조합, 이전 미리보기 무효화, 명시적 편집 반영, 변경 전후 금액·차이, 사용자 대기·완료·실패 상태, Enter 접기와 Space 체크를 확인했다.
- UI 미리보기 응답은 명시적으로 표시한 로컬 합성 fixture다. 실제 Spring 서비스 계산은 별도 테스트로 검증했다. fixture 페이지/API는 배포 코드에서 제거하고 재현 소스만 Git 제외 로그 디렉터리에 보존한다.

## 환경 실패와 미검증 범위

최초 Gradle은 한글 Windows 경로의 worker classpath 오류로 실패했고 기존 README 지침대로 R: ASCII 경로·저장소 Gradle cache를 사용해 성공했다. Next 개발 서버의 기존 하위 Node 20/EPERM 오류는 Node 22 프로덕션 빌드로 전환해 검증했다. Docker Desktop 엔진이 시작되지 않아 로컬 DB 통합 검사는 생략했으며 원격 CI의 PostgreSQL/Testcontainers 결과를 병합 전에 확인한다.

Agent migration 0007은 실행 시점의 prompt_version을 저장하며 기존 행과 구버전 실행의 기본값은 v1이다. 시작 시 Alembic migration을 수행하는 기존 배포 경로를 사용한다. 실제 운영 AI 의견의 품질, 실제 휴대폰, 고객 업무 전체 흐름, k6 부하와 전환율은 이번 검증에 포함하지 않는다. reduced-motion CSS 경로를 확인했지만 OS 설정 직접 전환은 수행하지 않았다. BYOK·외형/성향 생성은 후속 단계이며 기존 운영 적합성 보류 판정은 유지한다.

원격 CI·병합·배포 결과는 PR의 START 본문과 Actions/Vercel 기록에 연결한다.
