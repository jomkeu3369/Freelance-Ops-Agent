# 메인 소개 화면 개선·검증 — 2026-09-12

## 변경

- 기준: 최신 main `f3ecc79`(PR #33). 다른 PC의 페이지별 features 구조를 유지했다.
- `workflow-live-preview`가 12열 그리드 한 칸에 자동 배치되면서 카드·노드·문자가 겹쳤다. 전체 열과 너비를 명시하고 좁은 화면에서는 내부 그래프만 가로 스크롤하도록 수정했다.
- 밝은 보라색 도입부, 제품 예시·문의/초안 카드, 어두운 강조 구간, 근거 확인 배경과 마지막 시작 구간을 구성했다. 제품 화면 입체 등장, 스크롤 강조, 카드 등장과 결과 선택 전환을 적용했다.
- 시연의 일시 정지·다음 단계, 카드 조작 중 정지, 탭 비활성 시 정지를 제공한다. 시스템 동작 줄이기 설정 변경에 따라 GSAP를 정리하고 자동 시연을 멈춘다.
- 시연 이벤트의 반복 음성 알림을 끄고 실제 업무 실행의 `aria-live="polite"`는 유지한다. 단계 선택 상태와 스크롤 영역의 키보드 초점을 제공한다.
- 기존 소스 검사 helper가 Windows CRLF의 `\r`를 남겨 일으키던 테스트 7개 실패를 수정했다. 검사 항목과 기대 내용은 완화하지 않았다.

- 라이트/다크 첫 화면과 흐름 구간을 캡처·육안 확인했다. 모바일 전환 후 장식 카드 기울기가 남는 문제와 결과 카드 글자 대비, 제품 예시 상단 바 너비를 추가 보완했다.
- 일시 정지 후 `data-paused=true`, 다음 단계 클릭 후 이벤트 변화·정지 유지, 그래프 영역 ArrowRight 입력 후 `scrollLeft` 증가를 확인했다.
- 근거 항목 선택 시 연결 근거 변경, 결과 선택 시 `실제 21일` 표시를 확인했다.
- 동작 줄이기는 matchMedia 구독/해제와 CSS 정적 표시 경로를 코드로 확인했다. OS 설정을 직접 전환하는 브라우저 실험은 수행하지 않았다.

## 실패 기록과 범위

첫 개발 서버는 sandbox 하위 Node 프로세스의 EPERM으로 500을 반환했다. 해당 서버만 종료하고 권한이 허용된 Node 22 프로덕션 빌드로 전환해 검증했다. 이 오류를 제품 코드 문제로 우회하지 않았다. 최초 lint의 스크롤 영역 tabindex 경고는 키보드 스크롤을 위한 지역 예외와 설명으로 처리했다.

원시 로컬 로그는 Git 제외 `output/landing-review/`에 보존한다. 실제 휴대폰, 운영 AI 모델 호출·결제·고객 업무 데이터 쓰기, 전환율·사용자 성과 및 부하 테스트는 이번 소개 화면 검증 범위가 아니다. 실제 운영 적합성에 대한 기존 보류 판정은 변경하지 않는다.

별도 작업에서 작성된 AI 펫 제안 문서는 이번 PR에 포함하지 않는다. 원격 CI·Vercel 결과는 PR과 배포 기록을 기준으로 확인한다.
