## Implemented scope

- Local File chips for TXT/CSV/PDF/JPG/PNG/GIF; large paste becomes a UTF-8 TXT File without trimming or newline conversion. `NEXT_PUBLIC_CHAT_PASTE_THRESHOLD` defaults to 8000; accepted configuration range 1000–50000. Local files remain in memory until explicit reading, survive component navigation, expire after one hour and do not survive reload. Removal and local TXT preview are available.
- Reading and sending are two distinct steps. The user reviews extraction coverage and checks confirmation before sending. Failure/cancellation retains the draft. START retries include attachment IDs in their signature.
- Spring authenticates membership, `agent.run`, `project.read`, workspace/project scope and staging ownership. `V45__chat_attachments.sql` stores extracted text/coverage only, with a 30-minute expiry, scheduled cleanup, per-user quota and project/account cascading deletion. A canceled browser request may already have produced a staging row; expiry bounds this orphan retention.
- `POST /api/v2/workspaces/{workspaceId}/projects/{projectId}/attachments` accepts bounded multipart files; `DELETE .../attachments/{attachmentId}` removes staging. `POST /internal/v1/attachments/extract` uses the existing delegation token boundary and a local parser subprocess. START adds optional `attachmentIds`; internal `AgentInput` adds separate structured `attachments`.
- Six files, 2 MiB/file, 8 MiB total, 40,000 extracted characters, 30 PDF pages, 60 GIF frames, 16M pixels/image, 32M aggregate frame pixels, two concurrent parsers, 15-second reader timeout. Linux child limits add 512 MiB address space and 12 seconds CPU; Windows lacks the POSIX address-space limit. Overflow is rejected, not truncated. The preview alone explicitly labels its display limit.
- TXT/CSV: strict UTF-8, BOM-detected UTF-16, CP949; explicit encoding override. CSV supports comma/tab/semicolon/pipe, quoted multiline records and explicit delimiter override. Ambiguous auto-detection rejects with a retryable error. Formulas remain literal text. No spreadsheet execution occurs.
- PDF: reuse existing `pypdf`, strict parse, encrypted files rejected, per-stream zlib decompression bound. Text layer is **PARTIAL**; missing scans/images/layout are always disclosed. All-empty text layers are **UNSUPPORTED**.
- JPG/PNG/GIF: Pillow validates the actual format and loads bounded frames. OCR, image semantics, animation understanding and scan OCR are **UNSUPPORTED**. No model, OCR service, embedding or other external paid API is called for extraction. Existing multimodal cost guards are unchanged.
- Extracted data enters model prompts after routing, explicitly marked as untrusted reference JSON. It is excluded from routing/direct-operation/research queries. Existing Tool permissions remain authoritative; prompt instructions alone do not guarantee resistance to injection.
- START resolves attachments before reserving credits and consumes staging in its existing transaction. Existing replay happens first. Empty attachment lists preserve old serialized request hashes; the BYOK legacy-hash branch applies only when no attachments exist. This one-line condition in `FreeUsageService` must survive the separate usage-ledger integration.
