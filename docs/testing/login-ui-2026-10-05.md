로그인 배경, 영상 제어와 푸터를 순서대로 통합한 당시 기록이다. 현재 사용 계약은 [로그인 미디어 안내](../frontend/AUTH_BACKDROP_MEDIA.md)를 따른다. 아래 통과·실패·미실행 수치는 해당 후보에만 적용하며 최신 브라우저 결과는 [제품 근거](../portfolio/product-evidence.md)에서 확인한다.

## 배경과 폼

기준 `81ead5fdd94b98e83f4e5fe4daf8a558c4fe4b02`, 당시 브랜치는 `codex/login-pet-road-20261005`였다. 승인 이미지를 전체 배경으로 두고 오른쪽 폼을 분리했다. 원본 이미지는 비례 축소·압축했으며 기존 데모 카드와 안내문은 화면·번역에서 제거했다. 작은 화면·가입 폼은 문서 자체를 스크롤하고 인증·나이 확인·중복 제출 방지는 유지했다.

초기 언어·테마 제어 묶음은 후속 검수에서 홈으로 가는 브랜드만 남기는 구성으로 바뀌었다. 미디어 연결이 없던 초기 단계는 정지 화면만 표시했으며 이후 단계에서 실제 영상을 연결했다.

## 영상과 재생 제어

기준 `67dbab50aedec7ab7cbfe7fa6227b4a70c4e86bf`, 당시 브랜치는 `codex/login-pet-motion-20261005`였다. 영상 하나·첫 프레임 포스터·오프라인 네 프레임 전환을 기존 수명 관리에 연결했다. 실행 중 생성 서비스는 호출하지 않는다.

낮은 파일 경계 오차만으로 전환이 보이지 않는다고 판단하지 않았다. 이 영상을 60fps나 완전한 무봉제 반복으로 설명하지 않는다.

초기 후보는 단위 316개·타입·린트·webpack 빌드를 통과했다. 최종 44px 이모지 제어 보완 뒤 단위 320개·타입·린트를 통과했다. 수동 정지는 기존 정지 이미지로, 재생은 영상으로 전환하며 화면 밖 자동 정지는 사용자 선택을 보존한다. 당시 로컬 Chromium 검사는 실행되지 않았으며 브라우저 작성·수집을 통과로 세지 않았다. 공개 후보의 Actions에서 실제 디코딩·반복·정지 유지·재생 거부·오류·데이터 절약을 확인하도록 했다.

## 푸터와 좁은 화면

기준 `554fb14e0d90b0583d06ffd222434da9545ee692`, 당시 브랜치는 `codex/login-footer-center-20261005`였다. 기존 문구·운영 공지 링크를 문서 흐름 안에서 중앙 정렬하고 폼과 겹치는 고정을 피했다. 44px 영상 제어와 안전 여백을 두고 짧은 화면에서는 폼 뒤로 스크롤되게 했다.

로컬 Node.js 22의 `preview:check`에서 단위 322개·타입·린트·정상 운영 빌드를 통과했다. 첫 CI 브라우저 후보는 80개 통과·3개 실패로 좁고 낮은 폼의 떠 있는 제어 충돌을 드러냈다. 760px 이하에서는 푸터 왼쪽에 제어를 배치하고 기존 엄격한 겹침 검사는 유지했다. 한글·영문, 320/390px, 가로·짧은 가입 화면, 링크 접근과 스크롤 뒤 키보드 재생을 검사 대상으로 뒀다. 최종 재실행·운영 배포는 이 기록만으로 완료 판정하지 않는다.

모든 계정·응답은 합성 데이터였다. 실제 로그인·가입·유료 생성·DB 변경은 이 화면 검증에 사용하지 않았다. 미디어 원본·해시는 [자산 기록](../../frontend/public/login/README.md)에 보존한다.
