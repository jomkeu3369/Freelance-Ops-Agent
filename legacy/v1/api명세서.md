# 📡 Freelance-Ops-Agent API 명세서 (v1.0)

이 명세서는 `api.freelance-ops.site`를 기본 호스트로 하며, 모든 요청은 `application/json` 형식을 사용합니다.

---

## 1. 🔐 인증 및 보안 (Auth)

관리자 인증 및 보안 토큰 관리를 담당합니다.

| 메서드 | 엔드포인트             | 설명                | 필수 파라미터             |
| ------ | ---------------------- | ------------------- | ------------------------- |
| POST   | `/api/v1/auth/login`   | 관리자 로그인 및 JWT 발급 | `username`, `password`    |
| POST   | `/api/v1/auth/refresh` | 액세스 토큰 갱신    | `refresh_token`           |
| post    | `/api/v1/auth/logout` | 로그아웃        | `Authorization` Header    |
| GET    | `/api/v1/auth/me`      | 내 정보 확인        | `Authorization` Header    |
---

## 2. 📊 대시보드 (Dashboard)

대시보드 페이지의 실시간 데이터 및 시스템 상태를 제공합니다.

| 메서드 | 엔드포인트                   | 설명                        | 응답 예시                        |
| ------ | ---------------------------- | --------------------------- | -------------------------------- |
| GET    | `/api/v1/dashboard/stats`    | 주요 통계 (고객, 수익, 가동률) | `{"active_clients": 5, ...}`     |
| GET    | `/api/v1/dashboard/activities` | 최근 활동 타임라인          | `[{"action": "견적 생성", ...}]` |
| GET    | `/api/v1/dashboard/system`     | Vultr 상태                 | `{"cpu": 15, "ram": 45}`         |
| GET    | `/api/v1/dashboard/services`   | 외부 API(OpenAI 등) 연결 상태 | `{"openai": "online"}`           |

---

## 3. 👥 고객 관리 (CRM)

고객 정보 및 클라이언트별 대응 페르소나를 관리합니다.

| 메서드 | 엔드포인트              | 설명                          | 기능                             |
| ------ | ----------------------- | ----------------------------- | -------------------------------- |
| GET    | `/api/v1/clients`       | 전체 고객 리스트 조회        | 검색 및 필터링 지원              |
| POST   | `/api/v1/clients`       | 신규 고객 및 요구사항 등록   | 초기 페르소나 설정 포함          |
| GET    | `/api/v1/clients/{id}`  | 특정 고객 상세 및 대응 로그  | 대화 요약 포함                   |
| PUT    | `/api/v1/clients/{id}`  | 고객 상태 또는 전략 수정     | 진행 단계 업데이트               |
| DELETE | `/api/v1/clients/{id}`  | 고객 데이터 삭제             | 아카이브 여부 선택 가능          |

---

## 4. 🧠 에이전트 워크스페이스 (Agent Workspace)

LangGraph 기반의 Agentic RAG와 소통하고 견적을 산출하는 핵심 영역입니다.

| 메서드 | 엔드포인트               | 설명                          | 비고                       |
| ------ | ------------------------ | ----------------------------- | -------------------------- |
| POST   | `/api/v1/agent/chat`     | 에이전트와 대화 (RAG 실행)   | `client_id` 필수           |
| GET    | `/api/v1/agent/history`  | 대화 이력 불러오기           | 이전 컨텍스트 복구         |
| POST   | `/api/v1/agent/estimate` | 지능형 견적 산출 요청        | 태스크 분해 및 검색 수행   |
| POST   | `/api/v1/agent/approve`  | (HITL) 산출된 견적 최종 승인 | 승인 시 계약서 초안 생성   |

---

## 5. 🛠️ 유틸리티 도구 (Tone Styler)

커뮤니케이션 톤앤매너 조정을 돕는 도구입니다.

| 메서드 | 엔드포인트              | 설명                      | 입력 데이터                              |
| ------ | ----------------------- | ------------------------- | ---------------------------------------- |
| POST   | `/api/v1/tools/styler`  | 문구 스타일 변환 (비즈니스/부드러움) | `{"text": "...", "tone": "formal"}` |

---

## 6. ⚙️ 설정 및 아카이브 (Settings)

프로젝트 전역 설정 및 지식 베이스를 관리합니다.

| 메서드 | 엔드포인트                 | 설명                               | 대상 데이터              |
| ------ | -------------------------- | ---------------------------------- | ------------------------ |
| GET    | `/api/v1/archive/estimates` | 완료된 견적서 아카이브 조회       | 과거 이력 학습 데이터    |
| POST   | `/api/v1/rag/upload`       | RAG 학습용 문서 업로드 (PDF/TXT)  | 개인 지식 베이스 강화    |
| PUT    | `/api/v1/settings/keys`    | API 키 업데이트 (OpenAI, Tavily)  | `.env` 반영 로직 연동    |


## 7. 📋 로그 관리 (Logging)

프로젝트의 로그를 조회하고 관리합니다.

| 메서드 | 엔드포인트                  | 설명                               | 비고                     |
| ------ | -------------------------- | ---------------------------------| ------------------------  |
| GET    | `/api/v1/logs`             | 저장된 시스템 로그 목록을 조회      | 페이징, 필터, 검색 지원    |
| DELETE | `/api/v1/logs/{log_id}`    | 특정 ID의 로그를 영구 삭제         | 삭제 전 확인 요청          |
